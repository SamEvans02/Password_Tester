# Password_Tester
A repository for making a simple password tester. <br>
This will be copied into my "Website" repository when I get around to addign more substance to it. <br><br><br><br><br><br>




## Summary 
This is a fairly basic password tester, the features are listed down below in the next section. <br>
I made this for two main reasons: I am trying to better my general skills/knowledge and the sites I found online were good enough, but I thought I could make a better version for myself. <br>
Also, everyone uses passwords. So even though there isn't a line around the corner for my version of a password tester, it's still helpful. <br><br><br><br><br>


## Features 
    - Standard password testing: basic 
    requirements for strong passwords (NIST, Microsoft) 
    Link 1: https://pages.nist.gov/800-63-4/sp800-63b.html 
    Link 2: https://drata.com/blog/nist-password-guidelines 
    Link 3: https://support.microsoft.com/en-us/windows/create-and-use-strong-passwords-c5cebb49-8c53-4f5e-2bc4-fe357ca048eb 
    - A "Copy" button for convenience 
    - A "Generate" button which generates a *random strong password 
    - Entropy calculator for those who are interested 
    - I want this to remain simple, but am open to new ideas 
<br><br>


## Future Features 
    - Password reccomendations (based on current input) 
    - Modification to the "Generate" button: If a user already has input in the text box, randomization will use some of that, if left blank it will generate from scratch
